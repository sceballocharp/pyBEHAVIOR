# DMTS punishment audio

`white_noise.wav` is a mono 192000 Hz, 64-bit floating-point WAV exported from sound 110 of the original `Sounds/DMTS/AllSounds_from_wav.mat` bank. The original 96000 samples (0.5 seconds) were copied exactly, without normalization or gain changes. This file is independent of the MAT bank at runtime.

The app applies three repetitions and the 1.25x current sound-level gain during playback. Select another mono WAV through the DMTS FA noise file control if desired.
